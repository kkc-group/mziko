# Регистрация родителя в боте

Любой, кто напишет боту `/start`, за два ответа становится родителем: сначала
своё имя, потом имя ребёнка. В конце бот отдаёт код входа для ребёнка, то же
сообщение, что даёт `/code`. Раньше родитель появлялся в базе только если его
Telegram ID вписан в `ADMIN_TELEGRAM_IDS`, а имя не записывалось вовсе.

Макет: [docs/mockups/bot-registration.html](../mockups/bot-registration.html);
тексты приветствия и финала после правки 2026-09-29 —
[docs/mockups/bot-onboarding-intro.html](../mockups/bot-onboarding-intro.html).

## Как идёт диалог

1. **Имя родителя.** На `/start` от незнакомца бот здоровается, предупреждает,
   что сейчас один раз заводится первый ребёнок, а следующих добавляют потом
   одной командой, и спрашивает «Как вас зовут?». Под сообщением кнопка «Я — Имя Фамилия» с именем из
   профиля Telegram; её нет, если в имени профиля нет букв или оно длиннее
   100 знаков. Никнейм не предлагается. Ответ кнопкой или текстом.
2. **Имя ребёнка.** Бот повторяет записанное имя дословно («Записал: …») и
   спрашивает имя ребёнка. Вместо имени можно прислать код существующего
   ребёнка `LOMI-7241`, тогда второй родитель подключается к нему. Код
   принимается с дефисом, пробелом или слитно, в любом регистре.
3. **Готово.** «Вы в Мзико как …, добавил …» с командами на потом: первой
   идёт обещанная `/addchild Имя`, в хвосте — строка про кнопку «Кабинет»
   слева от строки ввода, где прогресс ребёнка показан экраном. Затем второе
   сообщение с кодом входа и ссылкой. При подключении по коду одно сообщение
   без повтора кода.

Ошибки ввода не выбивают из шага: стикер или голосовое — «Нужен текст»,
длиннее 100 знаков — «Длинновато: N знаков», неизвестная команда — просьба
сначала ответить на вопрос. Несуществующий код — «Ребёнка с кодом … нет»,
можно прислать имя.

`/cancel` на первом шаге ничего не сохраняет, на втором говорит, что родитель
уже записан и ребёнка можно добавить позже командой `/addchild`. `/help` у
зарегистрированного всегда показывает список команд, у незнакомца равен
`/start`.

## Как это устроено

Шаг визарда не хранится в памяти бота, а выводится из ответа API: родителя
нет — первый шаг, есть без детей — второй, есть с детьми — обычный `/start`.
Перезапуск бота ничего не теряет, а родитель, ушедший посреди диалога,
через день получает «С возвращением! Остался один вопрос».

Родитель создаётся сразу после первого ответа, а не в конце. Цена: в
бэк-офисе могут появиться родители без детей, список это показывает.

## Ручки API

| Ручка | Что делает |
|---|---|
| `GET /api/parent/me` | Родитель за Telegram ID из заголовка: имя и дети. 404 для незнакомца, а не 403, чтобы бот мог начать визард |
| `PUT /api/parent/me` | Создаёт родителя с именем или переименовывает. Имя до 100 знаков, не пустое |

Обе под секретом бота. Остальные ручки для незнакомцев по-прежнему 403, и бот
их сообщения молча пропускает: незнакомец, написавший `/report`, ответа не
получит, пока не пройдёт `/start`.

Имя ребёнка в `POST /api/parent/children` теперь тоже ограничено 100 знаками
и даёт 422 вместо ошибки базы.

## Что изменилось против прежнего поведения

- Регистрация открыта всем, `ADMIN_TELEGRAM_IDS` стал необязательным: он
  по-прежнему заводит родителей при старте API, но без имени.
- `/start` и `/help` разведены; появился `/cancel`.
- Обычный текст без команды раньше игнорировался, теперь это ответ визарда
  для тех, кто в нём находится; для остальных по-прежнему ничего.
- `/addchild` принимает код с пробелом: раньше `LOMI 7241` становился именем.
- Поле `name` у родителя заполняется; бэк-офис показывает его без правок.
- 2026-09-29: приветствие говорит, что регистрация одноразовая и заводит
  первого ребёнка; финал добавляет `/addchild Имя` и строку про кнопку
  «Кабинет». Строка про кабинет стоит в конце, потому что при нехватке места
  под шапку уезжают верхние строки, а хвост остаётся виден. Кнопки «Кабинет»
  нет, если `PUBLIC_URL` не https: текст на неё сошлётся всё равно, это
  принято как есть, на проде адрес https.

## За бортом

- Правка своего имени после регистрации: только повторным `PUT /me`, команды
  в боте нет.
- Регистрация команд бота в меню Telegram (`set_my_commands`) и описание
  бота в BotFather.
- Подтверждение «Да/Нет» перед сохранением имени: вместо него имя повторяется
  в следующем сообщении.
