# Тема «Дикие животные»

Документ отвечает на «как устроено» тому, кто код не писал.

## Что изменилось

В разделе «Слова» появилась тема «Дикие животные» (გარეული ცხოველები), сразу
после «Домашних животных»: 12 слов, два урока по шесть. Порядок слов —
медведь, заяц, обезьяна, лиса, волк, слон, лев, тигр, кабан, черепаха,
верблюд, жираф. Все показываются рисунками на прозрачном фоне
(`media/images/wild-animals/`). Рисунки пришли на белом фоне; фон убран заливкой
от краёв кадра (белое внутри животного — глаза, когти — не тронуто), дальше
штатный `make images` обрезал их до квадрата 384×384.

Шесть слов уже были в теме «Животные» (`animals`), а грузинское слово может
жить только в одной теме (`tests/test_seed.py`), поэтому они переехали вместе
со звуком: медведь, волк, лиса, заяц, лев, слон. У лисы сменилось написание:
было მელია (мелиа), стало მელა (мела), звук для неё создан заново. Остальные
шесть слов новые, звук у всех новых — временный, из `make tts`.

«Животные» остались с четырьмя словами (птица, бабочка, лягушка, мышь), одним
уроком, иконка осталась 🐻. Всего теперь 22 темы, 245 карточек и 33 урока.

## Экраны

Ничего нового: тема — строка в разделе «Слова» с иконкой 🦁, занятие идёт как
у любой темы. Место в пути задаёт строка `wild-animals` под `domestic-animals`
в `content/order.yaml`.

## База данных на сервере

Загрузчик контента только добавляет и обновляет и узнаёт слово по паре
«тема + slug»: слова, убранные из YAML, остаются в базе. Шесть переехавших слов
переносятся в новую тему на месте, как в `docs/features/domestic-animals.md`:
`id` слова не меняется, а `word_progress` и `answers` ссылаются на слово по
`word_id`, так что ступень изучения переживает переезд. Slug'и слов те же;
новое написание лисы seed запишет сам, когда найдёт `fox` в новой теме.

Выполнить один раз на проде **до** раскатки этой ветки (до первого запуска
seed, иначе он вставит шесть слов в новую тему заново и старые строки останутся
дублями в «Животных»):

```sql
BEGIN;

INSERT INTO topics (slug, title_ru, title_ka, icon, "order")
VALUES ('wild-animals', 'Дикие животные', 'გარეული ცხოველები', '🦁', 77)
ON CONFLICT (slug) DO NOTHING;
-- seed перезапишет title_ru/title_ka/icon/order штатными значениями при первом
-- запуске после раскатки; здесь важно только создать строку и получить id.

UPDATE words
SET topic_id = (SELECT id FROM topics WHERE slug = 'wild-animals')
WHERE topic_id = (SELECT id FROM topics WHERE slug = 'animals')
  AND slug IN ('bear', 'wolf', 'fox', 'hare', 'lion', 'elephant');

COMMIT;
```

`sessions.topic_id` — журнал уже сыгранных занятий, его не трогаем.

Следствие для детей: у кого «Животные» были пройдены, они пройденными и
остаются. А «Дикие животные» у такого ребёнка появятся в пути уже с
несколькими знакомыми словами, их ступень изучения сохранена.

## За бортом

- Озвучка шести новых слов и лисы — временная, из `make tts`.
- Грузинский текст и транскрипции ждут проверки носителем (`content/README.md`).
- Снимок `lessons-today.png` в руководстве для родителей показывает
  «Животных» с двумя уроками и устарел ещё с «Домашних животных»;
  переснимается по отдельной просьбе.
