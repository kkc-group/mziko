# Рисунки в теме «Приветствия»

Документ отвечает на «как устроено» тому, кто код не писал.

## Что изменилось

До 30.09.2026 все десять слов «Приветствий» показывались текстовыми
карточками: вместо картинки крупно написано само грузинское слово. Теперь у
каждого слова рисунок с одним и тем же мальчиком в зелёной худи:

| Слово | Рисунок |
|---|---|
| გამარჯობა — привет | машет рукой |
| ნახვამდის — до свидания | уходит и машет через плечо |
| მადლობა — спасибо | руки на сердце, улыбается |
| თუ შეიძლება — пожалуйста | ладони сложены, улыбается |
| კი — да | большой палец вверх |
| არა — нет | ладонь «стоп», хмурится |
| დილა მშვიდობისა — доброе утро | просыпается, солнце в окне |
| ღამე მშვიდობისა — спокойной ночи | спит с мишкой под луной |
| ბოდიში — извини | ладони сложены, виноватое лицо |
| როგორ ხარ — как дела | разговаривает с девочкой |

Что это меняет в занятии: текстовой карточке нельзя дать «Вспомни слово»
(картинка и ответ совпали бы), поэтому на повторении эти слова шли только как
«Послушай и найди». С рисунками повторение выбирает между двумя заданиями, как
у остальных словарных тем. Число тем, слов и уроков не изменилось.

## Как это работает

- **Тема** — `content/topics/greetings.yaml`: у всех слов
  `image: {kind: file, value: /media/images/greetings/<slug>.png}` вместо
  `kind: text`.
- **Картинки** — `media/images/greetings/<slug>.png`, 384×384, прозрачный
  фон. Подготовлены тем же одноразовым рецептом, что и у «Моей семьи» (см.
  `my-family.md`): источники 1024×1536 с белым фоном в голубой рамке, обрезка
  60 px с каждой стороны, заливка белого фона от края кадра по связности, затем
  `make images`. «Спокойной ночи» и «Доброе утро» — целые сцены (кровать, небо,
  окно); заливка убрала только белое вокруг сцены, подушки и одеяло целы. У
  «До свидания» под кроссовками осталось едва заметное светлое пятно тени:
  более жёсткий порог прогрызал штору и одеяло на «Доброе утро».
- **Звук** не менялся.
- **База на сервере**: загрузчик контента (`backend/app/seed.py`) обновляет
  `image_kind` и `image_value` у существующих слов на месте, `id` слов не
  меняется, прогресс детей сохраняется. Миграция не нужна.
- **Тесты**: `tests/test_seed.py` проверяет, что у каждой картинки из файла
  есть файл в репозитории.

## Что осталось за бортом

- Снимки экранов в руководстве для родителей не переснимались.
- «Как дела» нарисовано как разговор двоих: сам вопрос на картинке не виден.
