# Рассказы

## Что система теперь умеет

Кроме уроков из отдельных слов, в программе может стоять **рассказ**: короткий
связный текст (стихотворение, история), который ребёнок сначала слушает по
строкам, потом учит из него новые слова, отвечает на вопросы по тексту и в
конце слушает рассказ целиком. Первый рассказ — «Осень» (`autumn-story`) сразу
после темы «Времена года»: пять строк стихотворения, четыре слова (სექტემბერი,
ოქტომბერი, ნოემბერი, გრილა), три вопроса.

Рассказ для всей системы — обычная тема: он стоит в `content/order.yaml`,
открывается по правилу дня, его можно открыть или закрыть из кабинета
родителя, его слова дают наклейки, монеты и попадают в отчёты бота. Новые
разделы, экраны списка и ручки API не появились.

## Как устроено

- **Контент.** `content/topics/<slug>.yaml` с блоком `story: {lines, questions}`
  (формат — `content/README.md`, раздел «Stories»). Проверки при загрузке
  (`backend/app/seed.py`): вопрос ссылается на существующую строку, слова
  вопроса `<тема>/<слово>` существуют в любых темах и различаются картинкой и
  звучанием, слово не может называться `line-…`.
- **Хранение.** `topics.story` (JSONB, миграция `c5d6e7f8a9b0`); у обычной
  темы `NULL`.
- **Урок.** `build_session` (`backend/app/services/learning.py`) для темы с
  `story` собирает: 5 × `story_line`, знакомство со всеми новыми словами сразу
  (не по три), их «послушай и найди» и повторы, вопросы, `story_replay`.
  Повтор урока тоже начинается с рассказа.
- **Контракт.** Строка рассказа передаётся как `WordOut` со slug `line-<n>`,
  картинкой-сценкой и своим mp3. У вопроса — обычный шаг `listen` с полем
  `prompt` (какую строку проиграть), `word` остаётся правильным ответом. У
  `story_replay` поле `lines` — весь рассказ. На `story_line` и
  `story_replay` ответ не принимается (`NO_ANSWER_STEPS`).
- **Монеты.** Вопрос засчитывается слову-ответу, даже из другой темы
  («жёлтый» из «Цветов»): монета и ступень по обычным правилам. Отдельного
  бонуса за рассказ нет.
- **Приложение.** Экраны `StoryLine` и `StoryReplay` в
  `frontend/src/screens/Lesson.tsx`; сценка — скруглённый квадрат `.scene`;
  на экране «Путь» у рассказа подпись «рассказ · N слов» (`TopicOut.story`).
- **Медиа.** Сценки — `media/scenes/<slug>/line-<n>.webp` (768 px, `make images`
  делает их из PNG без обрезки), кэшируются service worker'ом. Звук строк —
  `media/audio/<slug>/line-<n>.mp3` (`make tts`).

## Что осталось за бортом

- Озвучка временная (синтез голосом Eka); перевод и транскрипции ждут носителя.
- Финальная фраза «მადლობა» из исходного текста в рассказ не вошла: это слово
  уже есть в теме «Приветствия».
- Бонуса за целиком прослушанный рассказ нет; вопросы только «послушай и
  найди», без «расставь строки по порядку».
- Снимков экранов рассказа в руководстве для родителей нет (переснимаются по
  отдельной просьбе).
