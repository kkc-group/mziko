# Тема «Домашние животные»

Документ отвечает на «как устроено» тому, кто код не писал.

## Что изменилось

В разделе «Слова» появилась тема «Домашние животные» (შინაური ცხოველები),
сразу после «Семьи»: 16 слов, два урока по восемь. Порядок слов — кошка,
собака, корова, свинья, коза, овца, осёл, лошадь, курица, бык, утка, гусь,
индейка, хомяк, петух, голубь. Все показываются рисунками на прозрачном фоне
(`media/images/domestic-animals/`).

Девять слов новые. Семь уже были в программе с эмодзи, а грузинское слово
может жить только в одной теме (`tests/test_seed.py`), поэтому они переехали
вместе со звуком и сменили эмодзи на рисунок:

| Слова | Откуда |
|---|---|
| кошка, собака, лошадь | «Первые слова» (`basics`) |
| корова, свинья, курица, овца | «Животные» (`animals`) |

«Первые слова» остались с восемью словами (яблоко, солнце, хлеб, мяч, рыба,
цветок, машина, вода), «Животные» — с десятью; обе темы стали одним уроком
вместо двух. Всего теперь 21 тема, 239 карточек и 31 урок: два урока ушли,
два пришли с новой темой. Иконка «Первых слов» осталась 🐶, хотя собака из
темы уехала.

Опорные слова у букв (`anchor` в `letters-2` … `letters-4`: კატა, ღორი, ცხენი,
ძაღლი) не тронуты: это подпись под буквой, а не карточка темы.

## Экраны

Ничего нового: тема — строка в разделе «Слова» с иконкой 🐄, занятие идёт как
у любой темы. Место в пути задаёт строка `domestic-animals` под `family` в
`content/order.yaml`.

## База данных на сервере

Загрузчик контента только добавляет и обновляет: слова, убранные из YAML,
остаются в базе. Семь переехавших слов переносятся в новую тему на месте, как
в «Моей семье» (`docs/features/my-family.md`): `id` слова не меняется, а
`word_progress` и `answers` ссылаются на слово по `word_id`, так что ступень
изучения переживает переезд. Slug'и слов те же, что были.

Выполнить один раз на проде **до** раскатки этой ветки (до первого запуска
seed, иначе он вставит семь слов в новую тему заново и старые строки останутся
дублями в прежних темах):

```sql
BEGIN;

INSERT INTO topics (slug, title_ru, title_ka, icon, "order")
VALUES ('domestic-animals', 'Домашние животные', 'შინაური ცხოველები', '🐄', 77)
ON CONFLICT (slug) DO NOTHING;
-- seed перезапишет title_ru/title_ka/icon/order штатными значениями при первом
-- запуске после раскатки; здесь важно только создать строку и получить id.

UPDATE words
SET topic_id = (SELECT id FROM topics WHERE slug = 'domestic-animals')
WHERE topic_id = (SELECT id FROM topics WHERE slug = 'basics')
  AND slug IN ('dog', 'cat', 'horse');

UPDATE words
SET topic_id = (SELECT id FROM topics WHERE slug = 'domestic-animals')
WHERE topic_id = (SELECT id FROM topics WHERE slug = 'animals')
  AND slug IN ('cow', 'pig', 'chicken', 'sheep');

COMMIT;
```

`sessions.topic_id` — журнал уже сыгранных занятий, его не трогаем: старые
занятия по «Первым словам» остаются занятиями по «Первым словам».

Следствие для детей: у кого «Первые слова» или «Животные» были пройдены, они
пройденными и остаются. А «Домашние животные» у такого ребёнка появятся в
пути уже с несколькими знакомыми словами, их ступень изучения сохранена.

## Тесты

Тесты считают темы, слова и уроки из YAML. Поправлены те, что были завязаны на
прежний состав «Первых слов»: первыми словами темы стали яблоко, солнце, хлеб
(`test_api.py`, `test_learning.py`, `test_seed.py`), а пример темы из
нескольких уроков в `test_lessons.py` теперь «Слоги» — «Первые слова» стали
одним уроком.
