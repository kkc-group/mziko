Вход по коду ребёнка

Заменяет Pair и Unpaired из Pair.tsx. Код вида LOMI-7241: четыре латинские буквы, тире, четыре цифры. Экран не вызывает системную клавиатуру — у него своя: сначала буквы по алфавиту, после четвёртой буквы она сама меняется на крупные цифры. Токены и классы .play, .prog, .big-num, .bad, .dim, .hills взяты дословно из styles.css; новые классы (.login, .code, .cell, .keys, .key, .msg, .lock-card) собраны только из них. Рамка 390×844 в масштабе 0,8; iPhone SE — 375×667.

Ввод кода

Буквы и цифры — две отдельные группы с подписями «буквы» и «цифры»; включённая группа подписана цветом. Пока не набраны все восемь знаков, «Войти» серая. Клавиша «ABC» на цифровой панели возвращает к буквам; стирание с первой цифры тоже возвращает к буквам.

Проверка и ошибки

При ошибке код не стирается: чаще всего ошибка в одной цифре, и переписывать весь код заново обидно. Клетки краснеют и трясутся, «Войти» серая, пока код не изменят, — чтобы тот же неверный код нельзя было отправить второй раз и потратить попытку зря. Попытки — жёлтые кружки, как монетки: сколько осталось, а не сколько потрачено.

Закрыт на час

Экран без клавиатуры: вводить всё равно нечего. Таймер считает по времени сервера, перезагрузка страницы его не обнуляет. Кнопка «Попробовать снова» появляется только в двух случаях — час прошёл или родитель открыл код в Telegram.

Успех и вход по ссылке

«Привет, Лука!» держится ≈1,5 с и сам уходит на главный экран. Ссылка /c/LOMI-7241 формы не показывает: код виден только для сверки, в пунктирных клетках, без курсора.

Узкий и низкий экран · iPhone SE 375×667 · длинное имя

Нет «чёлки» и полоски «Домой»: сверху 20 px, снизу 0. При нехватке высоты первым уменьшается Мзико, потом заголовок и высота клавиш; кнопка «Войти» и клетки кода не уменьшаются никогда. Имя длиннее двух строк обрезается многоточием (в базе имя до 100 знаков, родитель пишет его в боте как угодно).

Тёмная тема

data-theme="dark" на рамке. Масштаб 0,6. Курсор и подпись включённой группы — --word-color (жёлтый на тёмном).

Решения в спорных местах

  • Своя клавиатура вместо системной. Системная на iPhone открывает кириллицу, строчные и автоисправление, закрывает половину экрана и прыгает при смене поля. Своя — всегда заглавные латинские буквы и крупные цифры, и после четвёртой буквы переключается сама. Цена — нельзя вставить скопированный код; для этого есть ссылка.
  • Буквы по алфавиту, а не QWERTY. Ребёнок ищет букву по порядку, родитель найдёт её в любом порядке. 26 букв в семь столбцов — четыре ряда; стирание занимает две клетки в последнем ряду.
  • Одно сообщение на неверное слово и на неверные цифры. «Не тот код» не говорит, существует ли слово LOMI, — иначе по экрану можно перебирать имена кодов.
  • Что уступает при нехватке места. Сверху вниз: Мзико (72 → 48 px) → размер заголовка → высота клавиш (52 → 46, 60 → 52). Клетки кода, строка сообщения (её высота зарезервирована всегда, чтобы клавиатура не прыгала) и кнопка «Войти» не уменьшаются.
  • Родитель открыл код — слово остаётся набранным. После «Попробовать снова» в клетках уже стоит LOMI, курсор на первой цифре, подсказка сменяется на «Цифры теперь новые — посмотри в Telegram».
