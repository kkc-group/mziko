Занятие · какой набор картинок у слов

Один и тот же экран .lesson из Lesson.tsx в четырёх наборах картинок. Токены и классы — из styles.css; картинка из файла ложится в тот же .pic-img, что уже есть для image.kind: file. Телефон 390×844 CSS px, показан в масштабе 0,8. Картинка в круге — 96 px, в плитке — 64 px, как в продукте.

Светлая тема · три состояния

A — новое слово «медведь». B — «Послушай и найди»: звучит «დათვი», ребёнок сначала тронул лису (красная), потом медведя (зелёная), монеты нет — только с первой попытки. C — слово «юбка», для которого эмодзи нет ни в одном наборе.

Тёмная тема · состояние A

Та же карточка «Новое слово!» на тёмном фоне, data-theme="dark" на рамке. Масштаб 0,6.

Справка по наборам

Веса — среднее по четырём скачанным файлам (медведь, лиса, корова, лягушка). Бандл на 150 слов — это среднее × 150; сейчас в контенте 138 слов с эмодзи, 77 слов текстом и 10 цветов.
